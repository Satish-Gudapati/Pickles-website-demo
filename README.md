# Pickles Paradise - Premium Pickle Store

A beautiful and responsive website showcasing premium veg and non-veg pickles.

## Features
- Responsive design that works on all devices
- Beautiful color gradients inspired by pickle colors
- Interactive product cards
- Smooth animations
- Easy navigation between veg and non-veg sections

## Technologies Used
- HTML5
- CSS3 (with modern gradients and animations)
- JavaScript (for interactivity)

## Setup
1. Clone this repository
2. Open `index.html` in your web browser
3. No additional setup required!

## Project Structure
- `index.html` - Main webpage
- `styles.css` - Styling and animations
- `script.js` - Interactive features
- `README.md` - Project documentation
